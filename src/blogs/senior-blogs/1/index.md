# senior week 9/8 - 9/11

first blog post of the year. got a lot of plans senior year so gonna have to speedrun my projects and get things done and learn as much as possible

just like the start of every year, we spent this entire week cleaning the shop and setting it back up to function as normal. so a lot of sweeping, cleaning, and getting rid of old things was done.

i spent majority of the time blowing out the dust out of everyones computer and helping sweep the floor. since we have a spreadsheet which tracks the assignments that we all have (which we each individually choose to claim), i threw up the idea of making a leaderboard for it as a joke, but mr. christy liked that idea a lot.

so i spent the entire week creating this website, vibecoding majority of the website utilizing opencode zen's free tier. 

my goal with this website was to utilize the google sheet we have and fetch the data from it, something i've done before using google's api but struggled with a lot. for this website, however, it just downloads the published csv of the sheet and parses through the data to figure out the required fields and then hands that to the ui.

this website was modeled based off of the <a href="https://cs2tracker.gg/slurs-tracking" target="_blank"> cs2 slur tracker</a> and <a href="https://thedataviewer.com/" target="_blank"> hyperplexed's data viewer </a> websites. 

while this website is currently hosted on github pages and linked directly to my github account, i may connect this with the mvthsengineering website domain as a subdomain, just so it makes more sense.

overall, i'm happy with the overall website and will probably do something similar for my current keyclub website (which is broken rn).
