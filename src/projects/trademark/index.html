a 3d-printed recreation of chamber's trademark from valorant — a stationary trip designed to detect people and trigger when someone walks into it. the build combines a multi-part printed assembly, a hollow head for the electronics, and custom hardware running on an esp32-cam.

inspiration for the project

i play a lot of valorant, and recently came across videos of people making raze's boombot and killjoy's turrent from valorant, so i wanted to do something similar. i figured chamber's trademark would be a fun idea, so i decided to use that and turn it into an ai security camera of some sorts.

although i originally wanted to make it like a security camera, i decided to change up the purpose and use an ai to scan for my mothers face, turning off my computer if found. this way, i would be able to play games and then pretend to be doing something else without getting caught

image of the chamber trademark in game

start

i originally planned to make the electronics first then work on the 3d model, but after i accidently shorted miles's esp-32cam ai thinker, i had no choice but to start 3d modeling as much as possible before working on the electronics.

at the same time, i was looking at parts and figuring out how plausable a project like this would be. after the 3d model was all done, i started experimenting with esp32's for the first time using an esp32-c3 to send a packet to a laptop running a flask server to run a command.

had lots of issues with the wifi because the school wifi that i was running it on does not support esp32's connecting for some reason. however, this took a while for me to figure out because i simply thought the wifi was too weak and was running it on the laptop's hotspot instead.

before my parts came, i made sure to test with a different type of esp32 just to familiarize myself with flask and also working with esps

flask server that opens a tab after reading a request sent via button press

eventually, my parts from aliexpress finally came after being delayed an extra two weeks, and i could start by getting everything to work on a breadboard

electronics

i started small by connected my new esp32-cam ai thinker to wifi then getting the "simple webserver" example working before doing anything with the esp32-cam. i also made sure to unplug everything everytime i took off the esp32 to prevent accidently shorting like i did last time

after that, i connected the pir sensor and some lights to the esp32, running some sample code which turned on the lights everytime the pir sensor got activated

eventually, i switched to using a transistor to connect the lights to ground as i was running out of digital pins. at the same time, i spent some time looking up edgeimpulse, which would be used to run the ai locally on the esp32

i had lots of issues with the example code they gave me to take photos with my camera because the library doesn't support the ov5640 camera, which aliexpress shipped to me by accident. because of this, i decided to just give all the example code that takes photos for me via the esp32 camera to chat-gpt and had it create the same thing but making it work with my given hardware

although it wasn't perfect, i managed to get all my images and started training it on edgeimpulse before exporting it to my esp32 as a library (which is how the esp32 will run the ai)

pcb + schematic

with an entire proof of concept on my breadboard, i started collecting all the components and putting them into a library with 3d models attached to their footprints to check tolerances and other stuff

i found a model for practically everything besides the camera i was using for my esp32-cam and the pir sensor i was using, so i found the datasheet and gave it to claude to make (i got lazy)

it wasn't perfect because i'm broke and using the free plan on claude, but it had the general dimensions correct and i just fixed whatever was left and attached it to my footprints

additionally, because i don't have a wall outlet outside my room, i decided to make this battery powered. however, after doing some research by figuring out how much voltage and amps go through my circuit, i realized that i would want 5v rather than 3.3 and roughly 1A, as it would draw 900mA under peak load

with this in mind, i added the adafruit powerboost 1000c and i'm planning on using the vape batteries that i helped desolder from their vapes last year

on my final check before it got shipped, i realized i had some issues with the schematic / pcb being wired incorrectly / not enough clearance on my components, so i fixed those and it was finally sent to jlcpcb where they will be making it

final stretch

while i waited for my pcb to come back, i started spray painting my parts. since the original trademark is a golden color, i opted for yellow and a blue-magenta-esque color for the colored pannels the trademark has on it's head

before i did that, however, i made the side pannel inserts that will be sprayed with the other color, opting for blue-purple spray paint for it

and then i started spray painting

even though i'm a beginner at spray painting and it wasn't perfect, i got a result i was satisfied with started assembling things together.

present day / current progress

as of now, the pcb is sent to jlcpcb to be made, so i'm just waiting for it to return so i can solder my components and test everything to see if it works.
